# Budha

A GNOME app for [Hermes Agent](https://github.com/NousResearch/hermes-agent).

Budha (बुध) is the Sanskrit name for Mercury. Hermes, his Greek counterpart, is
the messenger of the gods.

Budha is in early design. See `docs/` for research, decisions and the spec.
